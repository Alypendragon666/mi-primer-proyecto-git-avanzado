# Guía para Contribuir

Gracias por interesarte en contribuir a este proyecto. Por favor, sigue estas pautas para mantener un flujo de trabajo ordenado y consistente.

## Mensajes de Commit
- Usa **commits semánticos**: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`.
- El título del commit debe estar en **imperativo** y tener máximo **50 caracteres**.

## Nombres de Ramas
- Sigue esta convención:
  - `feature/nombre-caracteristica`
  - `bugfix/nombre-bug`
  - `docs/actualizacion-doc`

## Tamaño de las Pull Requests
- Haz **Pull Requests pequeñas**, enfocadas en **una única tarea**.
- Describe claramente los cambios en la PR.
